# E-Commerce Order & Delivery Analytics

## 📌 Project Overview

This project analyzes e-commerce sales, orders, customers, payments, and delivery performance using SQL and PostgreSQL.

## 🎯 Business Objective

The main objective is to understand sales performance, customer behavior, product category performance, payment trends, and delivery issues.

## 🛠️ Tools & Technologies

* PostgreSQL
* SQL
* Power BI
* Excel

## 📊 Key Analysis

* Sales and revenue analysis
* Product category performance
* Customer analysis
* Order analysis
* Payment analysis
* Delivery performance
* Return analysis
* Monthly sales trends

## 💡 Key Insights

* Identified top-performing product categories.
* Analyzed revenue and sales trends.
* Evaluated delivery performance.
* Identified return and delivery issues.
* Compared category performance using business KPIs.

## 🏁 Conclusion

The analysis helps management understand which product categories are performing well and which areas require improvement in sales, customer satisfaction, returns, and delivery performance.
